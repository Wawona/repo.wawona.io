# Wawona Repo

Custom utilities for the Wawona compositor project.

Hosted at [repo.wawona.io](https://repo.wawona.io)

## Jailbreak only

This repository hosts a **real Debian APT flat repo** for jailbroken iOS (Procursus)
and Termux Android. It is **not** used by App Store builds of Wawona.

App Store–approved downloadable modules use **`wwn-apt`** (StoreKit + On-Demand
Resources). **`repo.wawona.io` is prohibited** on App Store builds — do not
reference, bundle, or link it from App Store documentation or the Wawona App
Store app.
